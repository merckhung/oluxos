Port ARM64 version to Raspberry Pi 4B (QEMU raspi4b)

- Added EL3-to-EL2 dropping code in boot.S to support bare-metal booting on QEMU raspi4b machine (which boots in secure EL3).
- Implemented global L1/L2 peripheral mapping page tables (l2_table_3) for Broadcom peripherals (UART0 at 0xFE200000, GIC-400 at 0xFF800000) mapped above 3GB.
- Configured thread creation to share the global peripheral tables in l1[3].
- Refactored UART, GIC, and userspace shell drivers to use board-conditional MMIO addresses depending on CONFIG_BOARD_RPI4.
- Added Bazel build targets for RPi4 userspace, kernel (rpi4_kernel_elf), and QEMU runner script (run_qemu_rpi4.sh).
- Added test scripts (test_rpi4.py, debug_rpi4_boot.py) for verification.
