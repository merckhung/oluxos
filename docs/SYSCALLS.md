# System-call ABI reference

OluxOS implements the **Linux AArch64 generic system-call ABI**:

- `svc #0`;
- the number in `x8`;
- arguments in `x0`–`x5`;
- the result in `x0`, with errors as `-errno`.

Static binaries linked against upstream musl run unmodified, and so do
BusyBox and Dropbear. Structure layouts, flags, errno values, signal
numbers and ioctl numbers are Linux's. The headers userspace builds against
are musl's plus the kernel ABI subset in
`toolchains/userspace/linux-headers/`.

Differences a porter should know:

- **No dynamic linking** yet: binaries must be static, with no
  `PT_INTERP`. `execve` also runs `#!` scripts.
- **Process model.** `fork`, `vfork`, `clone` (threads and processes) and
  `clone3` are available; `clone3` returns `ENOSYS`, so libc falls back to
  `clone`. There are no namespaces or cgroups, and `unshare`/`setns` do not
  exist.
- **Credentials.** uid, gid and supplementary groups are enforced for file
  permissions and signals. Capabilities are all-or-nothing: root has every
  capability.
- **Files.** Filesystems are tmpfs, devtmpfs and procfs in the kernel, plus
  FAT and ext4 through the userspace servers (`mount -t userfs`). There is
  no `inotify` and no extended attributes.
- **Memory.** There is no swap: `mlock` just pre-faults and `munlock` does
  nothing. There is no huge-page support, and `msync` does nothing because
  file mappings are private copies.
- **Scheduling.** SCHED_FIFO, SCHED_RR, SCHED_OTHER, SCHED_BATCH and
  SCHED_IDLE are available, with `nice` and CPU affinity.
- **Time.** CLOCK_REALTIME, MONOTONIC, BOOTTIME, the COARSE variants, and
  per-process and per-thread CPU clocks. `adjtimex`/`clock_adjtime` provide
  NTP-style slewing and frequency correction.

## OluxOS extensions

| Nr | Call | Purpose |
|---:|------|---------|
| 1000 | `olux_channel(int fds[2], int flags)` | Create a connected pair of message endpoints (`O_CLOEXEC`, `O_NONBLOCK`) |
| 1001 | `olux_msg_send(fd, buf, len, fds, nfds)` | Send a datagram of up to 64 KiB with up to 8 descriptors |
| 1002 | `olux_msg_recv(fd, buf, len, info, fds)` | Receive; `info` returns the kernel-attested sender pid, uid and gid |
| 1003, 1004 | *(reserved)* | Formerly `olux_sysinfo` and `olux_watchdog`; they return `ENOSYS`. Use `sysinfo(2)`, `/proc` and `/dev/watchdog` |

The userspace wrappers are in `user/lib/olux_ipc.c` and the ABI is in
`include/uapi/olux/ipc.h`. The userfs protocol spoken over channels is
defined in `include/uapi/olux/userfs.h`.

## Device interfaces (ioctl)

| Device | Interface |
|--------|-----------|
| TTYs, PTYs | termios (`TCGETS`/`TCSETS*`), `TIOCGWINSZ`/`TIOCSWINSZ`, `TIOCSCTTY`, `TIOCSPGRP`/`TIOCGPGRP`, `FIONREAD`, `TIOCGPTN`/`TIOCSPTLCK` |
| Sockets | `SIOCGIF*`/`SIOCSIF*` (address, netmask, flags, MTU, hardware address, index), `SIOCADDRT`/`SIOCDELRT`, `FIONBIO`, `FIONREAD`; private `SIOCOLUX_DHCP` (0x89f0) and `SIOCOLUX_DNS` (0x89f1) used by `netcfg` |
| `/dev/watchdog` | Linux watchdog API (`WDIOC_KEEPALIVE`, `WDIOC_SETTIMEOUT`, `WDIOC_GETTIMEOUT`, `WDIOC_GETTIMELEFT`, `WDIOC_GETBOOTSTATUS`, `WDIOC_GETSUPPORT`, magic close `V`) |
| `/dev/rtc0` | `RTC_RD_TIME`, `RTC_SET_TIME` |
| `/dev/i2c-N` | i2c-dev (`I2C_SLAVE`, `I2C_SLAVE_FORCE`, `I2C_RDWR`, `I2C_SMBUS`, `I2C_FUNCS`) |
| `/dev/spidevB.C` | spidev (`SPI_IOC_MESSAGE`, mode, bits per word, speed) |
| `/dev/gpiochip0` | OluxOS GPIO ioctls (`include/uapi/olux/gpio.h`): line value, function, pull, edge wait |
| `/dev/fb0` | `FBIOGET_VSCREENINFO`, `FBIOGET_FSCREENINFO`, `mmap` |
| `/dev/input/eventN` | evdev (`EVIOCGVERSION`, `EVIOCGID`, `EVIOCGNAME`, `EVIOCGBIT`, `EVIOCGRAB`) |
| `/dev/vcio` | Raspberry Pi firmware property mailbox (`IOCTL_MBOX_PROPERTY`, 0xC0086400) |
| Block devices | `BLKGETSIZE64`, `BLKSSZGET`, `BLKFLSBUF` |

## /proc

`/proc` has:
- the system files `meminfo`, `cpuinfo`, `stat`, `uptime`, `loadavg`,
  `version`, `cmdline`, `mounts`, `filesystems`, `interrupts`, `devices`;
- the kernel logs `kmsg` and `last_kmsg`;
- `sysrq-trigger`;
- `net/{dev,route,if_inet6,tcp,udp,tcp6,udp6,raw,raw6,unix}`;
- for each process: `stat`, `status`, `statm`, `cmdline`, `environ`,
  `comm`, `maps`, `mounts`, `exe`, `cwd`, `root`, `fd/`.
